# Decor-prod

## 📌 Короткий опис проєкту
Decor-prod — це веб-проєкт для демонстрації та керування товарами (декор/продукція) з повноцінною адміністративною панеллю.  
Основна мета проєкту — показати роботу з **бек-ендом**, серверною логікою, базою даних та авторизацією.

Проєкт реалізований **без використання фронтенд-фреймворків та UI-бібліотек** — уся логіка і верстка виконані вручну.

---

## 🧠 Основний фокус проєкту
- Back-end логіка
- Робота з сервером (Node.js + Express)
- Робота з базою даних (Firebase)
- Адмін-панель з реальним функціоналом
- CRUD-операції з товарами

Фронтенд використовується як необхідний інтерфейс для демонстрації бек-енд можливостей.

---

## 🛠 Використані технології

### Front-end
- HTML5
- CSS3
- Vanilla JavaScript

❗ Без React / Vue / Angular  
❗ Без Bootstrap, Tailwind чи інших UI-бібліотек  
👉 Уся верстка та логіка написані вручну

### Back-end
- Node.js
- Express.js
- Firebase (Firestore + Storage)
- Firebase Admin SDK
- Multer (завантаження файлів)
- UUID
- bcrypt / bcryptjs

---

## 📄 Сторінки сайту та функціонал

### `/`
Головна сторінка з базовою інформацією та навігацією.

### `/portfolio`
Сторінка з товарами / роботами.  
Дані підтягуються з бази даних.

### `/product`
Сторінка окремого товару з детальною інформацією.

### `/reviews`
Сторінка з відгуками та інтерактивними елементами.

### `/about`
Інформаційна сторінка про проєкт / компанію.

### `/admin` — Адміністративна панель
- Авторизація адміністратора
- Додавання нових товарів
- Завантаження зображень
- Редагування та видалення товарів
- Робота з реальною базою даних (Firebase)
